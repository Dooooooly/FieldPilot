경로 최적화 테스트 버전

변경 내용
1. 기존 16방향 클러스터링을 최종 순서 결정 방식에서 초기 후보 생성 방식으로 변경
2. 카카오모빌리티 단일 구간 도로거리/시간을 필요한 구간에 조회
3. 도로거리 캐시 적용
4. 직선거리 상위 3개 후보만 실제 도로거리 비교하여 API 호출량 제한
5. Multi-start 초기해 + 2-opt 개선 적용
6. 최적화 중 최대 도로 API 조회 횟수 80회로 제한
7. 기존 경로 표시/카카오맵/드래그 기능은 유지

테스트
- JavaScript 문법 검사: 통과
- 최적화 알고리즘 모의 API 테스트: 통과
- 모의 테스트 결과: 5개 경유지 전체 순서 반환, 도로조회 22회

실사용 전제
- 설정 탭에 카카오 REST API 키가 필요합니다.
- 실제 카카오 API의 응답/쿼터/네트워크 상태는 이 환경에서 인증키 없이 검증할 수 없습니다.
- API 호출이 실패하거나 80회 한도에 도달하면 해당 구간은 직선거리 추정값으로 보완합니다.
