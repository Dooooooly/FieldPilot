📋 사용 순서
Step 1 출발지 설정 - 검색창에 장소를 입력하거나 🎯 현재 위치 버튼으로 내 위치를 출발지로 설정
Step 2 경유지 추가 - 방문할 현장들을 검색해서 추가 (최대 15개)
Step 3 최적화 실행 - 버튼을 누르면 카카오맵 도로 데이터를 기반으로 가장 효율적인 순서 계산
Step 4 결과 확인 - 지도에 최적 경로 표시, 하단에 거리/시간/절약량 확인
💡 동작 원리: 어떻게 최적 경로를 계산하나요?
1. 후보 경로 생성 - 3가지 방식으로 초기 경로를 만듭니다
• 방향 기반: 출발지 기준 시계방향/반시계방향으로 묶어서 순서 결정
• 도로 기반: 카카오맵 API로 실제 도로 거리 측정 후 가장 가까운 곳부터 방문
• 직선 거리 기반: 직선거리 기준으로 가까운 곳부터 방문
2. 경로 개선 (2-opt) - 각 후보 경로를 최대 3번 반복하면서 교차 구간을 찾아 더 짧은 경로로 교체
3. 최종 선택 - 3가지 후보 중 총 거리(또는 시간)가 가장 짧은 경로를 최종 결과로 선택

💡 동작 원리: 주소는 어떻게 좌표로 변환되나요?
현장을 추가하거나 엑셀에서 가져올 때, 주소가 있으면 자동으로 카카오 지오코딩 API를 호출합니다.
변환 과정:
1. 주소를 카카오 서버에 전송
2. 도로명주소 우선 → 지번주소 순서로 좌표 확인
3. 좌표 + 전체 주소 + 행정동(동 정보) 저장
⚠️ 변환 실패 시: 주소가 잘못되었거나 카카오가 인식하지 못하는 경우입니다. 편집 버튼을 눌러 주소를 수정하거나 위도/경도를 직접 입력하세요.
💾 저장 위치: 모든 현장 데이터는 브라우저의 로컬 저장소(localStorage)에 저장되며, 데이터는 서버를 통해 route-data 저장소에 동기화됩니다.

📋 작업 기록 사용법

🔧 필수 설정 항목
👤 작업자 이름
작업 기록에 표시될 이름을 입력하세요. 저장하면 모든 기록에 자동으로 적용됩니다.
🔐 GitHub 연동
GitHub 토큰을 입력하면 현장 데이터가 자동으로 백업됩니다. 여러 기기에서 동일한 데이터를 사용할 수 있습니다.
생성 방법: GitHub → Settings → Developer settings → Personal access tokens
🗺️ 카카오 API 키
지도 표시와 주소 변환에 필요합니다. JavaScript 키와 REST API 키 모두 입력하세요.
생성 방법: developers.kakao.com → 앱 생성 → 키 발급
🔧 고급 기능
📍 드래그로 경유지 순서 변경
경로 탭의 최적화 결과에서 ⠿ 핸들을 드래그하면 순서를 바꿀 수 있습니다.
순서를 변경하면 지도의 경로도 자동으로 다시 그려지며, 각 구간별 거리/시간도 재계산됩니다.
단, 출발지(🚩) 위치로는 이동할 수 없습니다.
💾 프리셋 저장/불러오기
자주 사용하는 출발지 + 경유지 조합을 프리셋으로 저장할 수 있습니다.
저장한 프리셋은 한 번의 클릭으로 불러올 수 있어 반복 작업에 유용합니다.
저장 위치: 경로 탭 하단 "프리셋" 섹션
📊 엑셀 가져오기/내보내기
현장 탭에서 엑셀 파일(.xlsx, .xls, .csv)로 현장 목록을 가져오거나 내보낼 수 있습니다.
가져오기: 현장명, 주소 컬럼이 있으면 자동으로 인식하고 주소 변환을 실행합니다.
내보내기: 현재 현장 목록을 엑셀 파일로 다운로드합니다.
🗺️ 전체 경로 연결 (카카오맵 연동)
최적화 완료 후 🗺️ 전체 연결 버튼을 누르면 카카오맵 앱에서 전체 경로를 한 번에 확인할 수 있습니다.
카카오맵 앱 제한: 경유지 최대 5개 (초과 시 앞 5개만 전달)
❓ 자주 묻는 질문
주소 변환이 실패했다고 나와요 (⚠️ 표시)
주소가 잘못되었거나 카카오가 인식하지 못하는 주소입니다.
현장 탭에서 해당 현장을 클릭해서 주소를 수정하거나, 위도/경도를 직접 입력하세요.
예: "서울시 용산구 이태원동 123-4" → "서울특별시 용산구 이태원로 153"
지도가 안 나와요
설정 탭에서 카카오 JavaScript 키를 입력했는지 확인하세요.
키를 입력한 후에도 안 나오면 캐시 초기화 후 새로고침을 시도하세요.
설정 탭 → 업데이트 관리 → 캐시 초기화
데이터가 사라졌어요
데이터는 브라우저의 로컬 저장소에 저장됩니다. 브라우저 캐시를 삭제하면 데이터도 함께 삭제됩니다.
GitHub 토큰을 설정해두면 자동으로 백업되므로, 다운로드 버튼으로 복원할 수 있습니다.
설정 탭 → GitHub 연동 → 📥 다운로드
통계 기록을 눌렀는데 저장이 안 돼요
먼저 최적화를 실행한 상태인지 확인하세요. 최적화 결과 없이 통계 기록 버튼을 누르면 저장할 데이터가 없습니다.
GitHub 업로드 실패 시에도 로컬에는 저장되므로 걱정하지 마세요.
