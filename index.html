📖 사용 가이드
📍 1. 장소 탭 — 출발지 & 경유지 설정
1출발지 입력창에 지명 또는 주소를 입력하세요. 2검색 목록에서 선택하거나 ↑↓ Enter로 선택할 수 있습니다. 3경유지 입력창에서 추가할 장소를 검색하고 추가 버튼을 누르세요. 4최대 15개까지 경유지를 추가할 수 있습니다. 5⚡ 경로 최적화 버튼을 누르면 16방향 클러스터링으로 최적 경로를 계산합니다.
💡 입력창을 클릭하면 최근 사용한 출발지 3개가 자동으로 표시됩니다.
🗺️ 2. 경로 탭 — 지도 확인 & 상세 경로
최적화된 경로를 카카오 지도에서 확인합니다. 도로 경로 API를 통해 실제 도로 기준 경로를 표시합니다. (API 호출 실패 시 직선 연결) 경로 목록의 각 항목을 클릭하면 지도가 해당 위치로 이동합니다. 요약 패널에서 총 거리, 예상 시간, 방문지 수를 확인하세요. 📤 공유 버튼으로 텍스트 형태의 경로를 복사하거나 공유할 수 있습니다.
📋 3. 개소 탭 — 개소리스트 관리
➕ 개소 추가: 개소명과 주소를 입력하여 직접 등록하세요. 📥 엑셀 가져오기: CSV 또는 XLSX 파일로 일괄 등록할 수 있습니다. 📤 엑셀 내보내기: 현재 지역의 개소리스트를 백업합니다. 🔍 검색: 개소명 또는 주소로 실시간 필터링됩니다. ✏️ 편집 / 🗑️ 삭제: 각 개소의 정보를 수정하거나 제거합니다. 📍 지도 보기: 해당 개소의 위치를 경로 탭 지도에서 확인합니다. ➕ 경유지 추가: 개소를 현재 경유지 목록에 바로 추가합니다.
⚙️ 4. 설정 탭 — API 키 & 동기화
🔐 GitHub Token을 입력하면 데이터가 5초 후 자동 업로드됩니다. 🗺️ 카카오 JavaScript 키와 REST API 키를 모두 입력해야 지도와 검색이 작동합니다. 📋 히스토리: GitHub에 저장된 커밋 기록을 확인할 수 있습니다. 💾 설정 내보내기/가져오기: API 키를 JSON 파일로 백업 및 복원합니다. 🗑️ 초기화: 모든 지역 데이터와 설정을 삭제합니다. (복구 불가)
📊 엑셀 파일 양식
첫 번째 행은 헤더(컬럼명)로 작성해야 합니다.
개소명 | 도로명주소 | 비고(선택) | 위도(선택) | 경도(선택)
💡 위도/경도가 없으면 주소로 자동 변환됩니다. (카카오 REST API 키 필요) 💡 개소리스트가 비어 있을 때 내보내기를 누르면 예시 양식이 다운로드됩니다.
