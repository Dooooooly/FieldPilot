📖 사용 가이드
🗺️ 경로 탭
1. 출발지 설정
- 검색창에 출발지를 입력하고 '설정' 버튼을 누르세요.
- '🎯 현재 위치' 버튼으로 GPS 위치를 바로 설정할 수 있어요.
2. 경유지 추가
- 경유지명을 입력하고 '추가' 버튼을 누르세요.
- '📋 여러개 추가' 모드로 한 번에 여러 개를 추가할 수 있어요.
- 추가된 경유지는 드래그로 순서를 변경할 수 있습니다.
3. 경로 최적화
- '⚡ 경로 최적화' 버튼을 누르면 최적 경로가 계산됩니다.
- '가까운순/먼순' 중 최적화 방식을 선택할 수 있어요.
💾 프리셋 저장
- 현재 설정된 출발지와 경유지를 프리셋으로 저장할 수 있어요.
- 저장된 프리셋은 클릭 한 번으로 불러올 수 있습니다.
📍 지도 탭
📍 최적화된 경로를 카카오맵으로 확인하세요.
- 각 구간별로 다른 색상으로 표시되어 구분이 쉬워요.
- 경로 목록에서 클릭하면 해당 위치로 지도가 이동합니다.
- '🗺️ 카카오맵에서 열기' 버튼으로 실제 길찾기를 확인할 수 있어요.
📊 요약 정보
- 총 방문지 개수, 총 거리, 총 소요 시간을 한눈에 확인하세요.
📋 현장 탭
현장 관리
- '➕ 현장추가' 버튼으로 새 현장을 등록하세요.
- 현장을 클릭하면 이름, 주소, 비고를 편집할 수 있어요.
- '⭐ 즐겨찾기' 버튼으로 자주 가는 현장을 상단에 고정하세요.
📥 엑셀 가져오기/내보내기
- 엑셀 파일로 현장을 일괄 등록하거나 백업할 수 있어요.
- 지원 형식: .csv, .xlsx, .xls
🔍 검색 및 정렬
- 현장명이나 주소로 검색할 수 있어요.
- 이름순 또는 즐겨찾기 순으로 정렬할 수 있습니다.
⚙️ 설정 탭
🔐 GitHub 연동
- GitHub Personal Access Token을 입력하면 자동 백업이 가능해요.
- '📤 업로드'로 현재 데이터를 저장하고, '📥 다운로드'로 불러올 수 있어요.
🗺️ 카카오 API
- JavaScript 키와 REST API 키를 입력하세요.
- 지도 표시와 주소 검색에 필요합니다.
🔄 업데이트 관리
- '🔍 업데이트 확인' 버튼으로 새 버전을 확인하세요.
- '⚡ 캐시 초기화'로 오류를 해결할 수 있어요.
💾 데이터 관리
- '🗑️ 모든 데이터 초기화'로 모든 데이터를 삭제할 수 있어요.
💡 유용한 팁
📱 모바일 최적화
- 모든 화면이 모바일에 최적화되어 있어요.
- PWA로 설치하면 앱처럼 사용할 수 있습니다.
☁️ 데이터 백업
- GitHub에 백업하면 다른 기기에서도 데이터를 불러올 수 있어요.
